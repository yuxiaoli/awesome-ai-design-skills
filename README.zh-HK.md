面向 AI 代理的可重用設計技能與指引，涵蓋介面、動畫及刊物視覺設計，以及配套的設計系統參考與技能工作區。

## 介面設計與評審

透過明確的視覺與互動指引，協助 AI 代理建立、評審、重新設計或重建網頁及應用程式介面的技能。

- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - 為 AI 編程助手提供可搜尋的介面風格、配色、字體排版及用戶體驗指引，並支援建立設計系統。
- [Claude Code 前端設計](https://github.com/anthropics/claude-code) - Claude Code 儲存庫中的官方 frontend-design 技能，提供視覺方向、字體排版、佈局、動效及介面文案指引。
- [Taste Skill](https://github.com/Leonxlnx/taste-skill) - 可跨代理使用的前端設計、介面重新設計及視覺參考技能，涵蓋佈局、字體排版、動效與間距。
- [Impeccable](https://github.com/pbakaus/impeccable) - 面向 AI 編程代理的設計技能與檢視指令，提供字體排版、佈局、無障礙及前端品質指引。
- [AI Website Cloner Template](https://github.com/JCodesMore/ai-website-cloner-template) - 結合可重用的 clone-website 技能與 Next.js 範本，讓 AI 代理檢查現有網站、重建介面，並比較外觀與互動行為。
- [Hallmark](https://github.com/Nutlope/hallmark) - 面向 Claude Code、Cursor 及 Codex 的設計技能，支援建立、檢視及重新設計介面，並從參考中提煉可重用的視覺指引。

## 設計工作區與參考

協助 AI 代理組合及應用設計技能與視覺規則的工作區，以及可重用的設計系統參考。

- [OpenDesign](https://github.com/nexu-io/open-design) - 將可重用的代理技能、渲染範本及 DESIGN.md 設計系統與 AI 編程代理結合的設計工作區。
- [Awesome DESIGN.md](https://github.com/VoltAgent/awesome-design-md) - 供 AI 編程代理使用的 DESIGN.md 參考集合，分析網站的設計系統、設計變數及視覺規則。

## 原型、簡報與動效

面向互動原型、簡報及動畫設計的代理技能，提供可重用的視覺工作流程與動效實作指引。

- [Huashu Design](https://github.com/alchaincyf/huashu-design) - 用於製作 HTML 原型、簡報、動畫及資訊圖表的代理設計技能，包含品牌指引、設計評審及匯出工具。
- [GSAP AI Skills](https://github.com/greensock/gsap-skills) - GSAP 官方技能，指導 AI 編程代理使用動畫 API、時間軸、捲動效果及外掛，並處理框架整合與效能。

## 刊物與海報設計

運用可重用的構圖與風格指引，將相片、視覺參考及設計需求轉化為刊物插畫、拼貼作品及海報的 Codex 技能。

- [Gathered Scenes Zine](https://github.com/Zeejay0/gathered-scenes-zine-skill) - 透過構圖、抽象提煉、配色、紋理及字體排版，將相片轉化為紙質拼貼海報或原創刊物插畫的 Codex 技能。
- [GC Minimal Zine Poster](https://github.com/LiamGvchi/gc-minimal-zine-poster) - 用於製作紙張質感的極簡海報、分析視覺參考，並產生可重用風格規則與圖像生成提示詞的 Codex 技能。
- [Photo Abstract Editorial](https://github.com/ZzzLc0405/photo-abstract-editorial) - 將保留原貌的相片、從相片提煉的抽象畫面與簡短英文標題組合成直式刊物構圖的 Codex 技能。
