面向 AI 智能体的可复用设计技能与指引，涵盖界面、动画和刊物视觉设计，以及配套的设计系统参考与技能工作区。

## 界面设计与评审

通过明确的视觉与交互指引，帮助 AI 智能体创建、评审、重新设计或重建网页及应用界面的技能。

- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - 为 AI 编程助手提供可检索的界面风格、配色、字体排版和用户体验指引，并支持生成设计系统。
- [Claude Code 前端设计](https://github.com/anthropics/claude-code) - Claude Code 仓库中的官方 frontend-design 技能，提供视觉方向、字体排版、布局、动效和界面文案指引。
- [Taste Skill](https://github.com/Leonxlnx/taste-skill) - 可跨智能体使用的前端设计、界面重设计和视觉参考技能，涵盖布局、字体排版、动效与间距。
- [Impeccable](https://github.com/pbakaus/impeccable) - 面向 AI 编程智能体的设计技能与审查命令，提供字体排版、布局、无障碍和前端质量指引。
- [AI Website Cloner Template](https://github.com/JCodesMore/ai-website-cloner-template) - 结合可复用的 clone-website 技能与 Next.js 模板，让 AI 智能体检查现有网站、重建界面，并对比外观与交互行为。
- [Hallmark](https://github.com/Nutlope/hallmark) - 面向 Claude Code、Cursor 和 Codex 的设计技能，支持创建、审查和重新设计界面，并从参考中提炼可复用的视觉指引。

## 设计工作区与参考

帮助 AI 智能体组合和应用设计技能与视觉规则的工作区，以及可复用的设计系统参考。

- [OpenDesign](https://github.com/nexu-io/open-design) - 将可复用的智能体技能、渲染模板和 DESIGN.md 设计系统与 AI 编程智能体结合的设计工作区。
- [Awesome DESIGN.md](https://github.com/VoltAgent/awesome-design-md) - 供 AI 编程智能体使用的 DESIGN.md 参考集合，分析网站的设计系统、设计令牌和视觉规则。

## 原型、演示与动效

面向交互原型、演示文稿和动画设计的智能体技能，提供可复用的视觉工作流程与动效实现指引。

- [Huashu Design](https://github.com/alchaincyf/huashu-design) - 用于制作 HTML 原型、幻灯片、动画和信息图的智能体设计技能，包含品牌指引、设计评审和导出工具。
- [GSAP AI Skills](https://github.com/greensock/gsap-skills) - GSAP 官方技能，指导 AI 编程智能体使用动画 API、时间轴、滚动效果和插件，并处理框架集成与性能。

## 刊物与海报设计

运用可复用的构图与风格指引，将照片、视觉参考和设计需求转化为刊物插画、拼贴作品及海报的 Codex 技能。

- [Gathered Scenes Zine](https://github.com/Zeejay0/gathered-scenes-zine-skill) - 通过构图、抽象提炼、配色、纹理和字体排版，将照片转化为纸质拼贴海报或原创刊物插画的 Codex 技能。
- [GC Minimal Zine Poster](https://github.com/LiamGvchi/gc-minimal-zine-poster) - 用于制作纸张质感的极简海报、分析视觉参考，并生成可复用风格规则与图像生成提示词的 Codex 技能。
- [Photo Abstract Editorial](https://github.com/ZzzLc0405/photo-abstract-editorial) - 将保留原貌的照片、从照片提炼的抽象画面与简短英文标题组合成竖版刊物式构图的 Codex 技能。
