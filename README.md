Reusable design skills and instructions for AI agents, with design system references and workspaces for applying them to interfaces, animation, and editorial graphics.

## Interface Design and Review

Skills that guide AI agents in creating, reviewing, redesigning, or recreating web and app interfaces through explicit visual and interaction guidance.

- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - AI design skill with searchable UI styles, color palettes, typography, UX guidance, and design system generation for coding assistants.
- [Claude Code Frontend Design](https://github.com/anthropics/claude-code) - Official frontend-design skill in the Claude Code repository, with guidance on visual direction, typography, layout, motion, and interface copy.
- [Taste Skill](https://github.com/Leonxlnx/taste-skill) - Portable agent skills for frontend design, interface redesign, and visual references, covering layout, typography, motion, and spacing.
- [Impeccable](https://github.com/pbakaus/impeccable) - Design skill and review commands for AI coding agents, with typography, layout, accessibility, and frontend quality guidance.
- [AI Website Cloner Template](https://github.com/JCodesMore/ai-website-cloner-template) - Reusable clone-website skill and Next.js template for AI agents to inspect existing sites, rebuild their interfaces, and compare appearance and behavior.
- [Hallmark](https://github.com/Nutlope/hallmark) - Design skill for Claude Code, Cursor, and Codex that creates, audits, and redesigns interfaces and extracts reusable visual guidance from references.

## Design Workspaces and References

Workspaces and reusable design system references that help AI agents compose and apply design skills and visual rules.

- [OpenDesign](https://github.com/nexu-io/open-design) - Design workspace that combines reusable agent skills, rendering templates, and DESIGN.md design systems with AI coding agents.
- [Awesome DESIGN.md](https://github.com/VoltAgent/awesome-design-md) - Curated DESIGN.md references that analyze website design systems, tokens, and visual rules for AI coding agents.

## Prototypes, Presentations, and Motion

Agent skills for designing interactive prototypes, presentations, and animations, with reusable visual workflows and motion implementation guidance.

- [Huashu Design](https://github.com/alchaincyf/huashu-design) - Agent design skill for creating HTML prototypes, slide decks, animations, and infographics, with brand guidance, design review, and export tools.
- [GSAP AI Skills](https://github.com/greensock/gsap-skills) - Official GSAP skills that guide AI coding agents through animation APIs, timelines, scroll effects, plugins, framework integration, and performance.

## Editorial and Poster Design

Codex skills that turn photographs, visual references, and briefs into editorial illustrations, collages, and posters using reusable composition and style guidance.

- [Gathered Scenes Zine](https://github.com/Zeejay0/gathered-scenes-zine-skill) - Codex skills for turning photographs into paper collage posters or original editorial illustrations through composition, abstraction, color, texture, and typography.
- [GC Minimal Zine Poster](https://github.com/LiamGvchi/gc-minimal-zine-poster) - Codex skill for creating minimal posters with paper textures, analyzing visual references, and producing reusable style rules and image generation prompts.
- [Photo Abstract Editorial](https://github.com/ZzzLc0405/photo-abstract-editorial) - Codex skill that pairs a preserved photograph with an abstract panel derived from it and a short English title to create a vertical editorial composition.
